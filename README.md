# charitr-uae-website
UAE site for Charitr


## Website

The approved CHARITR corporate website is a buildless static site. HTML pages, styles, scripts and image assets are at the repository root; no dependency installation or build command is required.

### Preview locally

Run `python3 -m http.server 8000` from this directory, then open http://localhost:8000.

### Hosting

Publish the repository root using a static hosting provider. Configure the dedicated domain with that provider. The sitemap currently uses the Sites preview domain and should be updated when the production domain is selected.

### Before public launch

- Connect enquiry delivery: contact forms currently validate locally and do not send messages.
- Confirm final privacy, cookie and terms wording; some content still describes the prototype state.
- Complete desktop and mobile browser verification.

The images and approved logo assets are included. Sites-specific credentials, source history and local working files are excluded.
